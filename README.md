# The Last Scholar of Golb

A web game. Premise and design notes live in [`docs/design.md`](docs/design.md).

## Develop

```sh
npm install
npm run dev     # start the dev server
npm run build   # typecheck and build to dist/
```

## Play

The game is published to GitHub Pages from `main`:
<https://ethanthatonekid.github.io/last-scholar-of-golb/>.

## Controls

A/D or arrows change lanes, W/Up/Space jump, S/Down slide, P or Esc pause, M mute. Backtick opens
the debug panel in dev builds only; the published build does not include it.
